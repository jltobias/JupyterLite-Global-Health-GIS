# Contributing

Contributions are welcome when they keep the repository lightweight, browser-friendly, and safe for public training.

Please follow these principles:

- Use public, aggregated, redistributable data only.
- Keep notebooks small and restartable.
- Avoid heavyweight dependencies that are not available in WebAssembly/JupyterLite.
- Add citations and source metadata to every real-data notebook.
- Run `python scripts/smoke_test.py` before opening a pull request.
