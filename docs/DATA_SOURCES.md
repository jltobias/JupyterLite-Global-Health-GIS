# Candidate public data sources

## IHME / GHDx / GBD Results

Use for burden estimates such as DALYs, deaths, YLLs, YLDs, prevalence, incidence, and risk-attributable burden. Download through the approved IHME/GHDx workflow and document filters carefully.

## WHO Global Health Observatory

Useful for program indicators designed for public API access.

## World Bank

Useful for socioeconomic, population, health expenditure, and development covariates.

## Natural Earth or public boundary datasets

Use low-resolution country boundaries for training maps. Keep files small or host tiles/PMTiles externally.

## Humanitarian Data Exchange

Useful for selected operational layers when license, sensitivity, and update cadence are appropriate.
