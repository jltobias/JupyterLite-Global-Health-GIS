# Five-minute demo script

## 0:00-0:45 - Why browser-only matters

Open the JupyterLite URL and explain that learners do not need a JupyterHub, Binder launch, Google account, desktop GIS, or local Python install.

## 0:45-1:45 - Open the data

Run `00_welcome_global_health_gis.ipynb`. Show the warning that the bundled values are synthetic and explain how an approved IHME/GHDx subset replaces it.

## 1:45-2:45 - Run the pipeline

Open `01_gbd_data_pipeline_template.ipynb`. Show how a GBD-style CSV becomes a small GeoJSON and `.geolibre.json` project.

## 2:45-3:45 - JupyterGIS map

Open `02_jupytergis_global_health_points.ipynb`. Display the point layer or heatmap in JupyterGIS and discuss what belongs in notebooks versus GIS project files.

## 3:45-4:45 - GeoLibre story/project

Open `03_geolibre_project_launcher.ipynb`. Launch the same project in GeoLibre Web and show the story-map/dashboard possibilities.

## 4:45-5:00 - Close with program relevance

Emphasize reproducibility, low-friction training, transparent source metadata, and the ability to share a single URL with country teams.
